# 🌎 WildAtlas

> Explore. Discover. Remember.

WildAtlas is an open-source wildlife life-list platform designed to help naturalists, photographers, birders, anglers, divers, and explorers track every vertebrate species they have encountered.

## Goals

- Track every vertebrate species (~75,000)
- Personal life list
- Interactive Notion database
- Website & mobile app
- AI species identification
- GPS-based sighting logging
- Beautiful statistics and maps
